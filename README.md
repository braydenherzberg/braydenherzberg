## Selected projects

### Crater — research video analysis

[![Crater desktop app reviewing an interpolated crater profile, calibration, keyframes, and time-series export on its labelled synthetic practice clip.](assets/crater/02-review.png)](projects/crater.md)

**Research tool · Public release**<br>
